# LAEV-Agents 用户研究方案

## 研究目标

评估 LAEV-Agents 系统的可用性、有用性和用户体验，验证其在真实用户场景中的有效性。

### 具体目标
1. **可用性评估**: 测量系统的易学性和使用效率 (SUS评分)
2. **任务完成率**: 记录用户完成可视化任务的成功率
3. **用户满意度**: 收集用户对系统输出的主观评价
4. **定性反馈**: 通过访谈获取改进建议

---

## 参与者招募

### 目标人群
- **领域专家**: 8-10人
  - 无人机/低空经济从业者
  - 空中交通管理相关人员
  - 物流运营分析师
  
- **普通用户**: 8-10人
  - 数据分析师
  - 研究生/博士生

1. 年满18周岁
2. 具备基本的数据分析知识
3. 能使用普通话或英语进行交流
4. 有使用电脑和浏览器的经验

### 排除标准
1. 无法完成1小时实验的参与者
2. 与研究者有直接利益关系的人员

### 激励措施
- 每位参与者: ¥100-150 (或等值礼品卡)
- 提供实验参与证书 (可选)

## 实验设计

### 实验类型
**组内设计 (Within-subjects)**: 每位参与者使用两个系统
- 系统A: NL4DV (Baseline)
- 系统B: LAEV-Agents (我们的系统)

### 系统展示顺序
采用**拉丁方设计**平衡顺序效应:
- 50% 参与者: 先NL4DV → 后LAEV
- 50% 参与者: 先LAEV → 后NL4DV

### 实验时长
- 总计: 45-60分钟/人
- 系统A: 15-20分钟
- 系统B: 15-20分钟
- 问卷与访谈: 10-15分钟

## 实验任务

### 任务设计原则
1. **代表性**: 覆盖常见低空经济分析场景
2. **梯度难度**: 简单 → 中等 → 复杂
3. **可比性**: 两个系统使用相同/等价的任务

### 任务列表 (每个系统3个任务)

#### Task 1: 简单任务 (5分钟)
**场景**: 快速查看单一指标趋势

**NL4DV版本**:
> "请查看飞行操作量随时间的变化趋势"

**LAEV版本**:
> "显示飞行操作随时间的趋势"

**评估标准**:
- 是否生成折线图
- 是否包含时间轴
- 完成时间

---

#### Task 2: 中等任务 (7分钟)
**场景**: 多维度比较分析

**NL4DV版本**:
> "比较不同区域的飞行时长，并显示计划与非计划飞行的比例"

**LAEV版本**:
> "按区域排名总操作量，并显示计划与非计划飞行的比例"

**评估标准**:
- 是否正确分组
- 是否显示比例
- 图表清晰度

---

#### Task 3: 复杂任务 (8分钟)
**场景**: 综合探索性分析

**NL4DV版本**:
> "创建一个展示时间、空间和类别模式的综合分析"

**LAEV版本**:
> "提供一个显示时间、空间和类别模式的综合仪表板"

**评估标准**:
- 多图表组合
- 模式识别能力
- 交互性

## 测量指标

### 1. 客观指标

| 指标 | 测量方式 | 分析目标 |
|------|----------|----------|
| **任务完成率** | 成功/失败 | 系统有效性 |
| **任务完成时间** | 秒表计时 | 效率对比 |
| **错误次数** | 观察记录 | 易错点识别 |
| **求助次数** | 观察记录 | 学习曲线 |

### 2. 主观指标

#### System Usability Scale (SUS)
10个陈述，5点Likert量表 (1=强烈反对, 5=强烈同意)

1. 我想我会经常使用这个系统
2. 我发现这个系统 unnecessarily complex → 反向计分
3. 我认为这个系统容易使用
4. 我认为我需要技术人员的帮助才能使用这个系统 → 反向计分
5. 我发现这个系统的各个功能很好地整合在一起
6. 我认为这个系统有太多不一致的地方 → 反向计分
7. 我会想象大多数人会很快学会使用这个系统
8. 我发现这个系统非常 cumbersome to use → 反向计分
9. 我对使用这个系统感到自信
10. 我需要学习很多东西才能开始使用这个系统 → 反向计分

**SUS评分计算**:
- 奇数题: 得分 = 选项值 - 1
- 偶数题: 得分 = 5 - 选项值
- 总分 = 所有题得分之和 × 2.5
- 范围: 0-100，≥68为可用，≥80为优秀

#### 有用性评估 (5点Likert)
1. 系统生成的可视化符合我的预期
2. 系统能理解我的查询意图
3. 系统提供的可视化对我的分析工作有帮助
4. 与手动创建图表相比，这个系统节省了我的时间
5. 我愿意向同事推荐这个系统

#### NASA-TLX (可选，针对复杂任务)
- 心理需求
- 体力需求
- 时间压力
- 绩效水平
- 努力程度
- 挫败感

## 实验流程

### 1. 欢迎与介绍 (5分钟)
- [ ] 欢迎参与者
- [ ] 介绍实验目的和流程
- [ ] 签署知情同意书
- [ ] 确认激励方式

### 2. 背景问卷 (3分钟)
- [ ] 人口统计信息 (年龄、性别、职业)
- [ ] 数据可视化经验
- [ ] 低空经济领域知识
- [ ] 编程/技术背景

### 3. 系统A实验 (15-20分钟)
- [ ] 系统介绍 (2分钟)
- [ ] 练习任务 (3分钟)
- [ ] Task 1 (5分钟)
- [ ] Task 2 (7分钟)
- [ ] Task 3 (8分钟，可选)

### 4. 系统B实验 (15-20分钟)
- [ ] 同上流程

### 5. 问卷调查 (5分钟)
- [ ] SUS量表
- [ ] 有用性评估
- [ ] 系统对比偏好

### 6. 半结构化访谈 (5-10分钟)
访谈问题:
1. 你觉得哪个系统更好用？为什么？
2. 在使用LAEV时，有没有让你惊喜的地方？
3. LAEV生成的可视化质量如何？
4. 你觉得LAEV最适合什么场景？
5. 你希望LAEV增加什么功能？
6. 你会在实际工作中使用这个系统吗？

### 7. 结束 (2分钟)
- [ ] 感谢参与
- [ ] 发放激励
- [ ] 提供联系方式 (后续问题)

## 伦理考虑

### 知情同意
- 向参与者说明实验目的和流程
- 告知数据将匿名化处理
- 参与者可随时退出
- 签署书面同意书

### 数据保护
- 所有数据匿名化存储
- 录音/录像需额外征得同意
- 数据仅用于研究目的
- 保存期限: 研究结束后2年

### 风险最小化
- 无身体风险
- 心理风险极低
- 提供休息时间
- 允许跳过不舒适的问题

## 分析计划

### 定量分析
1. **描述性统计**: 均值、标准差、中位数
2. **配对t检验**: 对比两个系统的SUS评分
3. **Wilcoxon符号秩检验**: 任务完成时间非参数检验
4. **效应量计算**: Cohen's d

### 定性分析
1. 访谈录音转录
2. 主题编码分析
3. 关键引文提取

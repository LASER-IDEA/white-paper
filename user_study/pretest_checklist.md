# 用户研究预测试检查清单

在正式开始用户研究之前，进行1-2次预测试以发现和修复问题。

## 预测试目标

1. 验证实验流程是否合理
2. 检查时间估计是否准确
3. 发现任务设计问题
4. 测试数据收集工具
5. 确认技术环境稳定

---

## 检查清单

### 实验前准备

#### 技术环境
- [ ] 测试电脑可用
- [ ] 网络连接稳定
- [ ] 浏览器兼容性测试 (Chrome/Firefox/Edge)
- [ ] LAEV系统可正常访问
- [ ] NL4DV系统可正常访问
- [ ] 录屏软件工作正常 (如使用)
- [ ] 腾讯会议/Zoom功能正常 (线上实验)

#### 实验材料
- [ ] 知情同意书打印/准备好
- [ ] 背景问卷可访问
- [ ] SUS问卷可访问
- [ ] 数据记录表打印
- [ ] 访谈提纲准备好
- [ ] 计时器可用

#### 实验流程
- [ ] 任务描述清晰易懂
- [ ] 示例数据已加载
- [ ] 练习任务设计合理

---

### 实验流程测试

#### 开场 (5分钟)
- [ ] 介绍时间控制在3-5分钟
- [ ] 知情同意书签署顺利
- [ ] 参与者理解实验流程

#### 背景问卷 (3分钟)
- [ ] 问卷加载正常
- [ ] 题目清晰无歧义
- [ ] 填写时间约3分钟

#### 系统A实验 (15-20分钟)
- [ ] 系统介绍清晰
- [ ] 练习任务帮助理解
- [ ] Task 1: 能在5分钟内完成
- [ ] Task 2: 能在7分钟内完成
- [ ] Task 3: 能在8分钟内完成 (如包含)
- [ ] 系统无明显bug
- [ ] 数据记录顺利

#### 系统B实验 (15-20分钟)
- [ ] 同上检查点

#### 问卷 (5分钟)
- [ ] SUS题目理解正确
- [ ] 问卷提交成功

#### 访谈 (5-10分钟)
- [ ] 问题引导有效
- [ ] 时间控制合理
- [ ] 记录完整

#### 结束 (2分钟)
- [ ] 激励发放顺利
- [ ] 感谢语恰当

---

### 数据收集检查

#### 数据完整性
- [ ] 参与者编号正确记录
- [ ] 所有任务有时间记录
- [ ] SUS评分完整
- [ ] 访谈有记录

#### 数据质量
- [ ] 时间记录准确
- [ ] 成功/失败判断一致
- [ ] 错误次数计数准确

---

### 预测试反馈收集

向预测试参与者收集反馈:

1. **整体体验**
   - 实验流程是否清晰?
   - 时间长度是否合适?
   - 有没有感到困惑的地方?

2. **任务设计**
   - 任务描述是否清楚?
   - 任务难度是否合适?
   - 有没有无法完成的任务?

3. **系统体验**
   - 系统响应是否正常?
   - 界面是否友好?
   - 有没有技术问题?

4. **问卷设计**
   - 题目是否理解?
   - 有没有冗余题目?
   - 填写是否顺畅?

5. **改进建议**
   - 有什么建议?

---

### 预测试后调整

根据预测试发现的问题进行调整:

#### 可能的调整项
- [ ] 任务描述修改
- [ ] 时间估计调整
- [ ] 问卷题目优化
- [ ] 技术问题修复
- [ ] 流程顺序调整
- [ ] 指导语完善

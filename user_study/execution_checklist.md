# 用户研究执行检查清单

## 每日准备

### 实验前 (当天早晨)
- [ ] 确认参与者到达时间
- [ ] 检查实验场地/线上会议室
- [ ] 测试系统和网络连接
- [ ] 准备实验材料
  - [ ] 知情同意书
  - [ ] 数据记录表
  - [ ] 计时器
- [ ] 确认激励金/礼品卡

---

## 参与者到达时

### 接待
- [ ] 热情欢迎参与者
- [ ] 确认参与者身份
- [ ] 简要介绍实验流程
- [ ] 提供饮用水

### 知情同意
- [ ] 解释研究目的
- [ ] 说明实验流程和时间
- [ ] 强调自愿参与和随时退出权
- [ ] 解释隐私保护措施
- [ ] 签署知情同意书
- [ ] 询问是否同意录音 (如需要)

---

## 实验进行中

### 背景问卷 (3分钟)
- [ ] 发放/发送问卷链接
- [ ] 说明填写要求
- [ ] 等待完成
- [ ] 检查填写完整性

### 系统A实验
- [ ] **介绍** (2分钟)
  - [ ] 介绍系统功能
  - [ ] 演示基本操作
  - [ ] 确认理解
  
- [ ] **练习任务** (3分钟)
  - [ ] 指导完成练习
  - [ ] 回答问题
  - [ ] 确认准备好
  
- [ ] **Task 1** (5分钟)
  - [ ] 宣读任务描述
  - [ ] 记录开始时间
  - [ ] 观察并记录
    - [ ] 成功/失败
    - [ ] 错误次数
    - [ ] 求助次数
    - [ ] 特殊情况
  - [ ] 记录结束时间
  - [ ] 必要时提供帮助 (仅当参与者明确要求)
  
- [ ] **Task 2** (7分钟)
  - [ ] 同上流程
  
- [ ] **Task 3** (8分钟, 如包含)
  - [ ] 同上流程

### 系统B实验
- [ ] 重复系统A的完整流程

### 问卷填写 (5分钟)
- [ ] 发放/发送SUS问卷
- [ ] 说明评分标准
- [ ] 等待完成
- [ ] 检查完整性

### 访谈 (5-10分钟)
- [ ] 开启录音 (如同意)
- [ ] 按提纲提问
- [ ] 深入追问有价值的点
- [ ] 记录关键引文
- [ ] 感谢参与

---

## 实验结束后

### 结束程序
- [ ] 感谢参与者的时间和反馈
- [ ] 简要说明研究意义
- [ ] 回答参与者的问题
- [ ] 发放激励金/礼品卡
- [ ] 提供联系方式 (后续问题)
- [ ] 礼貌送别

### 数据整理 (当天)
- [ ] 检查数据记录表完整性
- [ ] 将数据录入电子表格
- [ ] 备份录音文件 (如适用)
- [ ] 整理访谈笔记
- [ ] 更新参与者追踪表

## 每周检查点

### 每周日晚
- [ ] 统计本周完成人数
- [ ] 检查目标进度
- [ ] 识别问题并调整
- [ ] 更新下周计划
- [ ] 联系下周参与者确认

---

## 应急处理

### 技术故障
- **系统无法访问**
  - [ ] 尝试刷新页面
  - [ ] 切换备用系统
  - [ ] 如无法解决，改期并道歉
  
- **网络中断**
  - [ ] 尝试重新连接
  - [ ] 使用手机热点
  - [ ] 如无法解决，改期

### 参与者问题
- **参与者迟到**
  - [ ] 等待15分钟
  - [ ] 联系确认
  - [ ] 决定是否改期
  
- **参与者身体不适**
  - [ ] 立即暂停实验
  - [ ] 提供帮助
  - [ ] 安排改期或退出
  
- **参与者想退出**
  - [ ] 尊重决定
  - [ ] 询问原因 (可选)
  - [ ] 按完成比例发放激励
  - [ ] 感谢参与

## 质量控制

### 数据质量检查
- [ ] 每次实验后检查数据完整性
- [ ] 每周汇总数据，检查异常
- [ ] 与预期样本量对比

### 研究者一致性
- [ ] 多名研究者时统一指导语
- [ ] 定期讨论确保评分标准一致
- [ ] 记录任何程序变更

- [ ] 至少完成 15 名参与者
- [ ] 领域专家 ≥ 5 人
- [ ] 普通用户 ≥ 5 人

### 理想目标
- [ ] 完成 20 名参与者
- [ ] 领域专家 8-10 人
- [ ] 普通用户 10-12 人
